# Conduit · Open WebUI · ARM64

[Русский](#русский) · [Release / Скачать](https://github.com/aktalascloud/conduit-owui-cline-arm64-performance/releases/latest) · [Applied patches / Патчи](patches/README.md) · [Upstream](https://github.com/cogwheel0/conduit)

Open WebUI client with Russian localization, voice avatars and optimized native Android libraries. Install the signed ARM64 APK and connect to your server. Build with Python 3.12+, Git and GitHub CLI using `Build.cmd status` and `Build.cmd build`.

Flutter release AOT and R8. SQLite, dartjni and ONNX Runtime/JNI use O3 ARMv8-A ThinLTO. Application ID and signing identity support upgrades. Keep credentials and model weights outside this checkout. Phone speed is unmeasured.

## Русский

Клиент Open WebUI с русским интерфейсом, голосовыми VRM и дополнительными провайдерами. Установите подписанный APK ARM64 и подключитесь к своему серверу. Для сборки нужны Python 3.12+, Git и GitHub CLI. Выполните `Build.cmd status` и `Build.cmd build`.

Flutter release AOT и R8. SQLite, dartjni и ONNX Runtime/JNI собраны с O3 ARMv8-A ThinLTO. ID и подпись APK сохраняются для обновления приложения. Данные и ключи храните отдельно. Скорость на телефоне не измерена.
