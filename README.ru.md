# Conduit OWUI + Cline ARM64

[English](README.md)

Неофициальный форк: проверенные исправления для агентов/MCP и дополненный русский интерфейс. Один актуальный APK.

[Upstream](https://github.com/cogwheel0/conduit) · [Release](https://github.com/aktalascloud/conduit-owui-cline-arm64-performance/releases/latest) · [Patches](patches/README.md)

Mainstream добавляет локальные черновики текста/записей с разделением аккаунтов, перемотку озвучивания, фильтр языков голосов, повтор подключения и элементы iOS. Native Cline и серверные VRM сохранены. Предупреждение upstream о версии сервера остаётся; проверка телефона и квалификация сервера 0.13 не заявляются.

Нативный Cline-чат использует темы Conduit, адаптивные отступы и режим действия. Аватар сверяется с сервером; закрытый кэш 100 МиБ проверяет SHA256 и загружает изменённые VRM. Личные аватары остаются на сервере.

Прямые подключения включают региональные пресеты MiniMax global/CN для M3.1 Flash и M3. Сохранённые ID моделей не меняются. Thinking Flash и история инструментов учитывают контракт провайдера; Responses передаёт историю с клиента. OpenRouter сохраняет модели и маршруты своего каталога. Эти дополнительные прямые профили используют ключ провайдера и не меняют FreeLLM. Доступность регионального Responses и реальный inference не проверены.

## Сборка

При обычном сохранении чата преобразуется только контент ассистента, точно совпавший с renderer сохранённого structured output. Сам output, буквальный текст, версии и локальные строки сохраняются; старые hash очереди совместимы с восстановлением после сбоя. Upstream может снова сформировать display content при изменении output. Массовой миграции истории нет.

Нужны Python 3.12+, Git и GitHub CLI для CI. Сборка не зависит от модели, её весов или Codex.

```cmd
Build.cmd status
Build.cmd build
```

`build` проверяет чистоту опубликованного коммита и запускает закреплённый workflow. При готовом локальном компиляторе/SDK: `Build.cmd local`. Зависимости, флаги, тесты и проверки лицензий — в `.avx1/`. Lockfiles и история исходников сохранены. Ключи подписи в репозиторий не входят.

## Установка и проверки

Установите единственный подписанный ARM64 APK. Пользовательские данные храните отдельно от исходников. Release AOT, происхождение нативных библиотек и реальные флаги указаны в манифесте. FPS на физическом телефоне не измерялся.

Последние проверки и замеры: [.avx1/measurements/latest.json](.avx1/measurements/latest.json). Микрозамеры CPU не означают скорость LLM. Исходные лицензии и уведомления сохранены.

Нативная сборка Android выполняется в Linux, как в CI. Для локальной сборки нужны те же закреплённые SDK/NDK и закрытые переменные `CONDUIT_KEYSTORE_BASE64` / `CONDUIT_KEYSTORE_PASSWORD`; их значения нельзя коммитить.

Эксперимент timeline из отозванных PR914/918 удалён. Нестабильность scrollbar/высоты длинных сообщений upstream остаётся известным ограничением; widget-тесты не подтверждают frame-time или производительность телефона.

Только наши текущие применённые изменения: [patches](patches/README.md).
