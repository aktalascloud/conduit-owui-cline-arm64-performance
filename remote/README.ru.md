# Удалённый доступ: OWUI + Cline

Conduit подключается к JSON-протоколу установленного Cline Hub через зашифрованный SSH-туннель. Чат, история, выбор проекта и модели, подтверждения инструментов работают на нативных виджетах Flutter с Markdown Conduit. Cline, провайдеры, сессии и файлы проектов остаются на ПК. В APK нет бинарника Cline, ключей провайдеров или готового адреса сервера.

## Windows

Установите Python 3.12+ и Cline Desktop. Скачайте исходники этого репозитория и выполните:

```powershell
.\remote\Setup.cmd -HostAddress your-host.example -ListenAddress 0.0.0.0 -Workspace C:\Projects\Example -InstallStartup -Start
```

Для другого CLI или профиля используйте `-ClineCli` и `-ClineConfig`. Настройка создаёт закрытую папку в Local AppData, постоянный ключ сервера Ed25519 и два независимых случайных кода доступа. Выводится только путь к файлу подключения. Существующие ключи сохраняются. Необязательный ярлык автозагрузки запускает шлюз независимо от Codex.

Для внешнего доступа разрешите входящий TCP 2222 для интерпретатора шлюза и пробросьте только этот порт на ПК. Порт панели 11280 оставьте на локальном интерфейсе. По возможности ограничьте адреса клиентов. Подписка на VPN не требуется.

## Android

Установите подписанный APK OWUI + Cline. Откройте **Начальный экран → Cline через SSH**, импортируйте закрытый `connection.json` с ПК и подключитесь. Передавайте этот файл лично; не публикуйте его. Параметры сохраняются только в защищённом хранилище телефона. Отпечаток сервера обязан совпадать; режима принятия любого ключа нет.

Откройте сессию из бокового списка либо выберите папку проекта на ПК и модель для нового чата. Существующие сессии сохраняют свою модель и каталог; перед отправкой явно выберите «План» или «Действие». Нативный интерфейс переведён на русский и английский. При необходимости войдите к провайдеру модели на ПК. После обрыва связи подключитесь снова и проверьте историю, прежде чем повторять сообщение с неизвестным исходом.

## Границы и безопасность

- Shell, SFTP, обратный туннель и произвольные TCP-адреса запрещены. Доступны локальная панель Cline и единственный RPC приёма файлов.
- Проверяются ключ сервера и отдельный код панели; ограничены подключения и попытки входа. Автоматического повтора команд нет.
- Подтверждения Cline сохраняются. Уже запущенный в Desktop ход может сохранять исходного владельца подтверждений; новые ходы из Conduit показывают нативные карточки разрешений с просмотром полного запроса.
- SSH не защищает интернет-канал от объёмного DDoS. Для такой защиты нужен сервис с защитой выше по сети либо закрытая VPN-сеть.
- Потеря связи с телефоном не означает повторную отправку сообщения. Перед ручным повтором действия с неизвестным исходом проверьте состояние сессии.

Лицензия Conduit — GPL-3.0. Cline устанавливается отдельно по собственной лицензии: [исходный проект](https://github.com/cline/cline). Уведомления зависимостей Dart SSH сохраняются; AsyncSSH распространяется по EPL-2.0 либо GPL-2.0-or-later. Конфигурацию, ключи и рабочие данные нельзя помещать в исходники и релизы.

## Изображения и документы

Кнопка скрепки передаёт файл через SSH в закрытую папку `user-uploads` на ПК. Проверяются размер и SHA256; повторная передача одинакового файла не создаёт копию. Максимум: 64 МиБ на файл, 1 ГиБ на папку, 4 вложения на сообщение. Изображения до 6 МиБ каждое также передаются через штатный `userImages`, в пределах суммарных 8 МиБ после кодирования; более крупные файлы доступны агенту по пути на ПК. Для понимания изображений нужна модель с поддержкой vision. Документы читает Cline своими инструментами с обычными разрешениями.

Файлы добавляются только к следующему сообщению, которое вы отправите сами. Вложения можно убрать перед отправкой. Готовые файлы — пользовательские данные; шлюз не удаляет их как кеш. Нет shell, SFTP и записи по произвольному пути. Голосовой ввод и звонки с телефона для этого подключения пока не реализованы. Голосовой ввод Desktop настраивается отдельно в Cline.
